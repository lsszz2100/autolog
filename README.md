# 오토로그 (AutoLog)

블로그 글쓰기를 돕는 Windows 데스크톱 프로그램입니다. AI 원고 작성, 대표 썸네일, 예약 발행, 체험단·기자단 원고, 숏폼 클립 만들기를 한 화면에서 다룹니다.

## 주요 기능

- **AI 원고**: 키워드와 글 스타일(정보형·후기형·꿀팁형)을 고르면 1,500자 이상 원고를 만듭니다.
- **대표 썸네일**: 1:1 카드형 대표 이미지를 자동으로 만듭니다.
- **예약 발행**: 여러 글을 원하는 시간에 순서대로 올립니다.
- **체험단·기자단**: 업체 가이드에 맞춘 원고, 사진·영상 순서 배치, 서식(굵게·형광펜·소제목).
- **숏폼 클립**: 올린 사진·영상으로 세로(9:16) 영상을 만들고 한글 자막과 한국어 나레이션을 넣습니다.
- **발행 기록**: 올린 글의 일시·제목·링크를 보관합니다.

## 개발 실행

- Windows: `run.bat` (처음 실행 시 필요한 패키지와 Chromium을 설치합니다. 환경 설치만 하려면 `setup.bat`)
- Linux / WSL / Mac: `./start.sh` (환경 설치만 하려면 `./setup.sh`)

대시보드는 `http://127.0.0.1:8765` 에서 열립니다. 브라우저 모드: `python app.py --browser`

## 설치 프로그램 빌드 (Windows)

- 지원 OS: Windows 10/11 64비트
- 필요: Python 3.12, Inno Setup 6 (`winget install JRSoftware.InnoSetup`)
- 빌드: `packaging\build_installer.bat` → `packaging\output\` 에 설치 파일 생성
- 사용자 데이터는 `%LOCALAPPDATA%` 아래에 저장되고, 비밀번호·API 키는 Windows 자격 증명 관리자에 저장됩니다.
